# Пример проекта

В файле example.tar лежит пример проекта. Содержит: 

- /example_design - проект для Vivado. Включает процессор и мигает светодиодом.
- /example_fsbl - пустой проект для Vitis, содержит fsbl.
- /u-boot-xlnx - U-Boot, добавлен sev и собран.
- /dts - все файлы используемые при создании dtb. backub-system.dts это system.dts до линьковки.
- /example_platform и /example_application - пример bare_metal приложения.
- /bootgen - все файлы используемые для создания образа.
