# Пример проекта на гитхабе

---
**REQUIREMENTS**

Для компиляции u-Boot требуется:

- DTG, должен быть установлен в /opt/xilinx, иначе нужно менять скрипт
- DTC
- arm-none-eabi-gcc

---

---
**NOTE**

Все файлы для процессора(FSBL, BSP, ....), кроме непосредственно кода приложения, генерируются по XSA файлу, и, соответственно, требуют перегенерации при изменении конфигурации процессора. U-Boot тоже необходимо перекомпилировать, даже если из него не планируется использовать измененную переферию. Это нужно по тому, что второе ядро обращается к переферии через первое ядро.

На гитхабе лежит 6 директорий:

-  fpga/
-  dts/
-  u-boot-xlnx/
-  fsbl/
-  cpu1_platform/
-  bare_metal/
-  boot/

fpga - проект c дизайном для ПЛИС. Содержит файлы исходного кода, ограничений, скрипты и т. д. необходимые для создания проекта. За создание проекта отвечает файл fpga.tcl, генерируемый Vivado. Для удобства создания проекта был написан create_project.sh запускающий скрипт с определенными настройками.    
dts это директория для генерации Device Tree. Содержит скрипт для генерации DTB. Если путь установки DTG отличается от /opt/xilinx, то в скрипте нужно его поменять    
u-boot-xlnx - подмодуль гит с U-Boot. Для компиляции - make_uboot.sh.     
fsbl содержит скрипт для генерации проекта в Vitis.    
cpu1_platform - проект Hardware Platform, нужен для генерации BSP. Скрипт помимо создания проекта добавляет флаги для компиляции, нужные для AMP.    
bare_metal - проект Application, с приложением.   
boot - скрипт для генерации загрузочного образа.
